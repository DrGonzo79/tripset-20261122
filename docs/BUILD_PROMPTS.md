# Phased build prompts

1. **Concierge validation:** instrument inventory confirmation, rule match, approval/rejection and coach escalation. Add no AI. Recruit 10 travelers with upcoming trips and collect $29 prepayment.
2. **Coach rule authoring:** add authenticated coach workspaces, versioned intent/substitution graphs, import provenance, audit events and override review. Write property tests proving unapproved rules never execute.
3. **Assisted inventory:** add photo upload with a low-cost vision model that returns candidates and confidence. Require human confirmation, benchmark on varied hotel photos, and measure false positives by equipment class.
4. **Production hardening:** threat model sensitive program data; add consent, retention/deletion, rate limits, encryption, error monitoring, backups, accessibility audit, legal terms and insurance review. Deploy the API only after explicit hosting approval.
